# ProMax Уведомления

Статическое веб-приложение для iOS 16.4+. Safari создаёт Web Push подписку с публичным VAPID-ключом MAX. ProMax регистрирует её в собственной WEB-сессии MAX. Сервер сайта не хранит токены MAX, сообщения или ключи подписок; APNs provider key для этого варианта не нужен.

Разместите файлы в корне HTTPS-домена. `sw.js`, `push-core.js`, `app.js`, HTML и manifest должны обновляться без долгого HTTP-кеша. В nginx отключите access log: ссылка привязки содержит данные подписки. Сайт не подтверждает привязку по одному нажатию: успешную регистрацию показывает IPA, а отметка о доставке появляется только после события `push` в service worker. Местный тест показа не меняет эту отметку.

Установите IPA 1.0.2+, подключите WEB-сессию в настройках уведомлений, откройте сайт в Safari и добавьте на экран «Домой». Запустите созданную иконку, разрешите уведомления, создайте подписку, свяжите с ProMax. Проверяйте настоящее сообщение с другого аккаунта на заблокированном iPhone.

Проверка JavaScript: `node --experimental-vm-modules test/promax_web_push_test.mjs` из корня проекта. Физическая доставка MAX и ограничения режима «Фокусирование» проверяются на iPhone.

Маршруты уведомлений и VAPID-ключ сверены с проектом ProMax Push. Его MIT-лицензия сохранена в `UPSTREAM-LICENSE`.
