Перед установкой

Это официальный клиент MAX?

Нет. ProMax — независимый клиент с собственным оформлением и дополнительными настройками. Для общения используется твой аккаунт MAX.

Почему старый preview не обновляется поверх?

У preview beta 11 и подписанных выпусков ProMax разные сертификаты. Для перехода сначала сохрани нужные локальные данные. Обычные обновления между выпусками с постоянным ключом поддерживаются.

Как установить на iPhone?

На сайте доступен неподписанный IPA. Его нужно подписать своим сертификатом через совместимый инструмент. Обычное нажатие на файл не устанавливает приложение в iOS.

Какие данные уходят на сервер ProMax?

Сервис раздаёт список выпусков и объявления. Диагностика ошибок отключается в настройках; отчёт о плавности отправляется вручную при включённой диагностике. Ссылка настроек хранит параметры в части адреса после #, без загрузки их на сервер.
