# ProMax для iPhone

Модификация открытого клиента [Komet](https://github.com/KometTeam/Komet), основанная на `v0.5.0-dev.22`. Исходный код Komet и его авторство сохранены; лицензия — [GPL v3](LICENSE). ProMax не является официальным клиентом MAX.

## Сборка и установка

[GitHub Actions](https://github.com/stillemptyNOW/ProMax/actions/workflows/promax-ios.yml) проверяет код, криптографическое ядро, обработку звука и сервер уведомлений, затем собирает `ProMax-ios-unsigned.ipa` на macOS. IPA доступен в артефактах успешного запуска. Для установки через eSign требуется действующая подпись. Минимальная версия — iOS 15.

Идентификатор приложения: `io.github.stillemptynow.promax`. Приложение устанавливается отдельно от Komet; потребуется повторный вход. Обновление из канала Komet отключено, чтобы оно не заменило ProMax.

## Изменения первой тестовой версии

| Функция | Что реализовано | Проверка на iPhone |
|---|---|---|
| Имена контактов | Полное имя профиля; пользовательское имя не наследует фамилию автоматически | Требуется проверка ответов MAX |
| Поделиться контактом | Пункт в профиле отправляет штатное вложение CONTACT в выбранный чат | Требуется |
| Поиск участников | Поиск по загруженным страницам группы, продолжение загрузки; исправлена остановка на повторной странице | Требуется для больших групп |
| Не отправлять прочтение | Отдельная сохраняемая локальная отметка; после синхронизации просмотренные сообщения не должны снова становиться непрочитанными | Требуется после перезапуска и смены устройства |
| Быстрая реакция | Выбор из каталога MAX в настройках ProMax, применение двойным нажатием с учётом разрешённых реакций чата | Требуется |
| Данные профиля | Копирование ID и серверная дата регистрации, если MAX её возвращает | Дата-центр MAX не сообщает; значение не выдумывается |
| Кружок из галереи | Долгое нажатие: запись или выбор видео; квадратное кадрирование по центру, первые 60 секунд | Требуется на разных форматах видео |
| Звонки | Переключение камеры, защита от позднего подключения камеры после завершения звонка, адаптивные кнопки | Требуется проверка соединения и звука между устройствами |
| Голос | Нормальный, низкий, гелий, робот, рация; обработка исходящего WebRTC аудио | Требуется прослушивание собеседником |
| Маски | Очки, визор, кошачьи ушки; обработка исходящих кадров с обнаружением лица | Требуется проверка камеры, поворотов и производительности |
| Цифровой ID | «Повторить» при «Технической заминке» запрашивает свежую авторизацию вместо закрытия экрана; сбой необязательной проверки биометрии не блокирует документы; ожидание HTTP ответа ограничено | Работа сервиса, биометрии и Госуслуг, устранение самой «Технической заминки» не подтверждены |
| Уведомления | Исправлены отрицательные ID групп; добавлены регистрация APNs и экспериментальное подключение к собственному серверу | Прямые фоновые push не подтверждены |
| Приватность | Отладочные логи отключены по умолчанию; убраны чувствительные URL и содержимое консоли цифрового ID | Не является полным аудитом безопасности |

## Уведомления

Купленный или общий сертификат eSign сам по себе не даёт доступ к серверной отправке APNs. Для прямых уведомлений ProMax нужны профиль с `aps-environment`, совпадающий App ID и ключ APNs владельца Apple Developer. Встроенная локальная проверка уведомлений не проверяет фоновые push.

Экспериментальный сервер находится в [server/apns-relay](server/apns-relay/README.md). Он принимает зашифрованный WebPush MAX и передаёт общее уведомление через APNs. Принятие собственного endpoint сервером MAX и доставка на реальный iPhone ещё требуют проверки. Секреты и сертификаты в репозиторий не добавляются.

Без этих ресурсов доступен существующий вариант Komet с веб-уведомлениями через Safari и веб-приложение на домашнем экране (iOS 16.4+). Это отдельный канал уведомлений. CallKit/PushKit для входящих звонков в фоне в этой версии не реализованы.

## Шифрование

Сохранено E2EE Komet v2: Monocypher, обмен ключами и Double Ratchet, проверка отпечатков собеседников. Протокол совместим с Komet и ProMax. E2EE нужно включить в диалоге на совместимых клиентах; оно не включается автоматически только из-за названия приложения. Самодельные криптографические алгоритмы не добавлены. Сервер уведомлений не получает ключи E2EE диалогов.

## Проверка перед использованием

Это тестовая версия. Зелёная сборка подтверждает компиляцию и автоматические проверки, но не подтверждает работу всех функций с текущим сервером MAX. После установки проверьте контакты, повторный вход, реакции, кружки, цифровой ID и обычный звонок. Для эффектов нужен второй собеседник, который проверит полученные звук и видео. Для уведомлений нужны отдельные проверки при закрытом приложении и после перезагрузки iPhone.

О найденных ошибках можно сообщать в [Issues](https://github.com/stillemptyNOW/ProMax/issues), указывая версию iOS, шаги воспроизведения и наблюдаемый результат. Не прикладывайте токены, сертификаты, пароли, реальные сообщения и документы.
