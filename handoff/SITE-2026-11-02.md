# ProMax · proma-x.xyz

Владелец поручил самостоятельно улучшить сайт через Frontend Design и опубликовать на VPS 2.26.230.233. Предыдущее ограничение «не публиковать» отменено этим запросом. Новая beta 13 обсуждается и проверяется, её публикация этим этапом не требуется.

## Дизайн

Светлая площадка приложения: белый #ffffff, фон #f5f7ff, текст #17243e, вторичный #52627b, синий #3267e9, подсветка #e9efff. Unbounded для коротких заголовков, Inter для текста. Настоящие синтетические снимки интерфейса вместо нарисованного чужого мессенджера. Выравнивание влево, широкая демонстрация приложения, отдельная заметная зона загрузок, затем подробности и ответы об установке. На телефоне — один столбец и доступные кнопки ОС.

Исходный тёмный макет с кислотным акцентом слишком общий. Новая версия связывает оформление с диалогами и ресурсами ProMax. Не используем декоративные номера секций, капслок-подзаголовки и непрерывные анимации. Один выразительный элемент — композиция из интерфейса и диалоговых форм.

## Порядок работ

1. Проверить новый VPS, действующий TLS и существующие сайты без изменения чужих сервисов.
2. Обновить HTML/CSS/изображения и иконки ОС с указанием лицензий. Сохранить загрузки из GitHub, каналы, контрольные суммы и инструкции по ОС.
3. Найти и воспроизвести ошибки загрузок и перехода на новый домен. Проверить исправления Node, Python и Flutter-тестами.
4. Сохранить совместимость старых ссылок настроек, новые создавать на proma-x.xyz. Обновить адрес сервера для beta 13.
5. Проверить мобильную и настольную страницы в браузере. Развернуть отдельный каталог выпуска и переключить сервис с возможностью отката. Существующую базу на новом VPS не заменять.
6. Проверить публичные HTTPS, API, реальные ссылки файлов и работу старого адреса. Записать результаты и оставшиеся ограничения beta 13.

## Проверяемые случаи

- Последний выпуск ещё содержит не все платформы: выбирается последний доступный файл нужной ОС.
- Стабильных выпусков нет: понятное пустое состояние и доступная ссылка на GitHub.
- Смена ОС или версии не оставляет чужую ссылку и не блокирует клавиатуру.
- Старые ссылки настроек продолжают импортироваться; чужие домены не принимаются.
- DNS обслуживает Cloudflare, backend доступен только через существующий nginx; перезагрузка не затрагивает VPN.
