# Аудит beta 12

## Производительность

Проверены конкретные участки кода, без заявления об измеренном FPS на физическом Android:

- `main.dart`: глобальный `GlobalAtmosphereOverlay` удалён; `ChatBodyLayout` помещает атмосферу между фоном и списком сообщений.
- `liquid_glass.dart`, `glossy_pill.dart`: плоский бюджет не создаёт `BackdropFilter`; средний использует одно размытие вместо рефракции. Это проверяется widget-тестами.
- `atmosphere_overlay.dart`: спрайты и частицы переиспользуются, вместо отдельной отрисовки каждой частицы используется атлас; количество и частота ограничиваются бюджетом.
- `ambient_clock.dart`: между ограниченными кадрами ticker останавливается; таймер отменяется при остановке и dispose.
- `motion_blur_box.dart`: режим плавности и слабый автоматический бюджет запрещают фильтр; подписка на бюджет снимается при dispose.
- `chat_list_screen.dart`: невидимые страницы отключают ticker через `VisiblePageTickers`.
- `api.dart`: JSON журнала провода разбирается только при наличии потребителя; MessagePack/Zstd уже выполняет Rust, переносить их из Dart не требуется.
- `chat_wallpaper_view.dart`: размер декодирования изображения ограничивается размером отображения. Небольшие PNG стикеров существующий оптимизатор отправляет без перекодирования в JPEG.

## Удаления

По запросу владельца удалены клиентский ignore list, streamer mode, добавление шрифта по URL, удаление у всех/обоих и wipe-for-both. Удалены настройки, UI, обработчики и относящиеся к ним тесты, устаревшие preferences очищаются при загрузке.

Дополнительная подтверждённая заглушка: в `e54124e:lib/frontend/screens/chats/chat_admin/admin_section.dart` обработчик «Статистика канала» только вызывает `showHintBubble(...channelStatsUnavailable)`; запроса и результата статистики нет. Кнопка удалена. Тест обновлён: реальные счётчики остаются, заглушки нет. Локальная статистика чата сохранена.

Остальные функции не удалялись по предположению о неработоспособности.

## Уведомления

В beta 11 локальный read watermark отбрасывал повторные Dart-события, но не чистил сохранённую `MessagingStyle`-историю Android. Кроме того, дедупликация в памяти терялась при перезапуске headless engine. Теперь watermark передаётся в native, просмотренная история обрезается, а идентификаторы уведомлений сохраняются по аккаунту/чату в одной транзакции SQLite. iOS получает время сообщения и удаляет доставленные уведомления до локальной границы просмотра.

Регрессионные сценарии: watermark в native payload, частичное чтение, перезапуск движка, параллельные уникальные сообщения и конкурирующие дубликаты. Данные синтетические. Проверено временным отключением передачи watermark и постоянной дедупликации: оба регрессионных теста падают, после восстановления исправлений проходят.

## Ограничения проверки

APK/AAB локально не собираются. Нативные сборки и C/C++ проверки выполняются GitHub Actions. Работа PiP, системного перевода и сегментации на физическом устройстве в этой среде не проверена; успешная компиляция не заменяет такую проверку.

## Дополнение владельца: профиль, каналы и VPS

Добавлены карточка собственного публичного профиля, копирование ID, opt-in бета-канал, служебные объявления и диагностика на FI (`boriskino.qd.je`). Схема админки и ограничение персональных данных описаны в `server/promax-hub/README.md`. Сервер не получает MAX-токены; номер телефона не используется как серверное доказательство роли. Объявления проверяются в приватном preview до подтверждённой публикации. APNs для закрытого iPhone не настраивается по решению владельца, применяется синхронизация при работе приложения.
